## 🎵 Glaze Music — my new app

**A desktop music player that treats your own files and YouTube Music as one library.**

Built with Electron + React. Windows installer, no account needed for local playback.

![Glaze Music home screen](https://raw.githubusercontent.com/shami60/glaze-music/main/docs/screenshots/home.jpg)

- Your local files and YouTube Music, side by side in one sidebar
- Lyrics that highlight **word by word** as the song plays
- A real **10-band equalizer**, with presets
- Offline downloads, queue with history, 8D audio and crossfade
- Light and dark themes, and updates that install on quit

![Full-screen player with lyrics](https://raw.githubusercontent.com/shami60/glaze-music/main/docs/screenshots/lyrics.jpg)
